# Chocolate-Factory-Sales-Analysis
Analysis of sales and production data for a chocolate factory using Power BI.

## 🍫 Project Overview
This is a practice project where I analyzed a Chocolate Factory dataset to understand sales performance, product trends, and geography-wise distribution.

## 🛠️ Tools Used
- **Power BI:** For data visualization and DAX.
- **Power Query:** For cleaning and transforming the raw data.
- **Excel:** As the primary data source.

## 📊 Key Features & Analysis
- **Total Revenue & Profit:** Tracked overall financial performance.
- **Product Performance:** Identified the top-selling chocolate types.
- **Regional Analysis:** Mapped sales across different countries/regions.
- **DAX Implementation:** Created measures for Profit Margin and Total Units Sold.
